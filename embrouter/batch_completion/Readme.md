# Implementation of `embrouter.batch_completion`, `embrouter.batch_completion_models`, `embrouter.batch_completion_models_all_responses`




EmbRouter Python SDK allows you to:
1. `embrouter.batch_completion` Batch embrouter.completion function for a given model.
2. `embrouter.batch_completion_models` Send a request to multiple language models concurrently and return the response
    as soon as one of the models responds.
3. `embrouter.batch_completion_models_all_responses` Send a request to multiple language models concurrently and return a list of responses
    from all models that respond.
